# Hikwo PDF Katalog

Her sabah 06:17'de (Türkiye saati) hikwo.com'daki **Silikon Kalıp** kategorisini okur, ürün fotoğraflarıyla bir PDF katalog üretir ve yayınlar.

- Katalog sayfası: https://hcmehmetkaya.github.io/hikwo-katalog/
- Doğrudan PDF: https://hcmehmetkaya.github.io/hikwo-katalog/katalog.pdf

Elle yenilemek için: **Actions → Günlük PDF katalog → Run workflow**.
Bölümler ve başlık `build_catalog.py` dosyasının başındaki ayarlardan değiştirilebilir.
